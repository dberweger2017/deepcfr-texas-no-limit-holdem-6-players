# Repository guidance

Read [ROADMAP.md](ROADMAP.md) before starting a task. Its **How we work** section defines the branch, commit, push, PR, review, and merge workflow, along with code-comment conventions and decisions reserved for the owner.

Use **Current position** to select the next task and update it when work lands. The roadmap records direction and acceptance checks; it does not schedule unattended work. Consult [docs/rules.md](docs/rules.md) before changing game behavior or player information.
