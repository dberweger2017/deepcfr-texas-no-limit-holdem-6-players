# Repository guidance

Read [ROADMAP.md](ROADMAP.md) before starting a task. Its **How we work** section defines the branch, commit, push, PR, review, and merge workflow, along with code-comment conventions and decisions reserved for the owner.

Use **Current position** to select the next task and update it when work lands. The roadmap records direction and acceptance checks; it does not schedule unattended work. Consult [docs/rules.md](docs/rules.md) before changing game behavior or player information.

Large untracked artifacts and cleanup destinations are indexed in [RESULTS_INDEX.md](RESULTS_INDEX.md). Keep working files wherever convenient; at cleanup archive them to the designated Google Drive folder with manifests, failures and retrieval provenance. Verify cloud completion/hashes and obtain owner authorization before deleting or evicting valuable local evidence. Current uploads are pending verification; preserve originals and other agents’ dependencies.
