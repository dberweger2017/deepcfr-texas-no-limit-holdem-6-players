# Pinned poker engine license check

The v0.4 source install builds `dberweger2017/pokers` at commit `5db20e3d5d6862b32a7402035c1340b622d3b005`. That repository is a fork of [`Reinforcement-Poker/pokers`](https://github.com/Reinforcement-Poker/pokers). **I license my changes on top of upstream under MIT**, consistent with this repository's [MIT license](../../../LICENSE.txt). The original authors' terms still need confirmation.

**Finding, 2026-09-30:** no upstream license grant was found. The upstream GitHub API reports `license: null`; its current recursive tree and tags `v0.1.0`, `v0.1.1`, `v0.1.2` contain no LICENSE/LICENCE/COPYING/NOTICE file. Upstream `README.md`, `Cargo.toml` and `pyproject.toml` do not declare a license. The [published `pokers` 0.1.2 PyPI metadata](https://pypi.org/project/pokers/0.1.2/) has no license field or classifier. The pinned fork likewise reports no GitHub license and no package license metadata. This is an absence-of-evidence check, not a determination that every copyright holder has withheld permission privately.

GitHub's [licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) distinguishes the right to view/fork a public GitHub repository from a general grant to modify and distribute it. MIT on my changes cannot automatically relicense upstream-derived engine code. If upstream rights holders publish an MIT license covering the relevant revision, preserve its copyright and license notice in the fork. Alternatively obtain written permission from the relevant rights holders and record its scope. There is no suitable temporary restrictive license we can grant over code owned by those authors; until permission is established, describe the upstream-derived part as **license unverified**, with its rights reserved by the original authors. I authorized v0.4 publication with that explicit disclosure and no engine binary while seeking confirmation from the original authors. Do not claim the whole fork is MIT before then.

This issue does not require renaming the repository or replacing the trainer. The release bundle is the B100M inference export and small metadata files; it contains no engine binary or papers. I have separately authorized distribution of that fixed model export for v0.4.
