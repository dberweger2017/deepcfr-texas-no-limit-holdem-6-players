## Fixed work and failure rules

Every new live or hypothetical native resolve completes exactly 50 iterations. The Python preparation/tree/process/parse deadlines and Rust harness timer are disabled in this explicitly bound mode. Native completion must acknowledge the protocol, exact iteration count, pinned solver and compression. Identical cached complete matrices remain reusable under the original cache/lock law. Preflop/flop base play remains the intended arm behavior.

Any attempted search fallback to base for any cause—timeout, memory refusal, unsupported holding, zero support, invalid response, unavailable solver, lost conditioning or a failed hypothetical probe—is a defect. Raise before selecting an action, stop global work and retain the request, receipt, response, logs and partial hand for owner review. There is no accepted fallback sample or fallback-rate threshold. There are no automatic retries, retunes, reduced counts or restarts.

**The original LBR opponent has an additional five-second soft timer.** When slow search preparation consumes that allowance, it can stop after one of four requested batches, changing the opponent by host. In the new arena both arms retain the same cap2 menu, four samples, chance law, seeds and estimator, but must finish all four batches. Its elapsed time and any descriptive overrun stay separate from action selection. This necessary timer amendment is explicit; retaining it would defeat the requested host independence.

Per-decision telemetry retains solve elapsed seconds, CPU model, cgroup quota/affinity and solver threads. Latency tables are descriptive and separate from paired strength contrasts. Host admission checks memory and quota, not a latency target. Configure one-thread Python numerical pools. Worker capacity is `min(floor(quota/6), floor((RAM - 2 GiB)/(9 GiB)))`, with a 9-GiB family ceiling and 2-GiB pod reserve; there is no fixed four-CPU or latency-headroom reservation.

The operational hang detector records an owner-attention flag at **100 × the actual host’s measured reference-request p99**. It never substitutes an action, cancels a solve, drops a hand, or declares scientific failure solely for elapsed time. Pending hands and every failure/partial remain retained. Independent correctness, memory, disk and financial guards can stop an incomplete campaign; such a stop preserves partial evidence and never supplies a base action or a completed scientific result.
