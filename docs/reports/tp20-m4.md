# Three-player 20BB M4 learning pilot

## Result

**The frozen six-lineup primary is positive:** final-current trained minus same-game uniform is **+58.84 [+53.92, +63.75] BB/100**, with the prespecified 95% stratified block interval. All three independent from-zero seed aggregates are positive. The early-to-final crossplay diagnostics also favor the final checkpoints.

Learning improvement is established on this restricted three-player panel. Absolute profit against the five scripted lineups remains unestablished, and tight-passive play regresses relative to uniform. No six-player, tournament, equilibrium or professional-strength claim follows. No model is promoted; [PR #113](https://github.com/dberweger2017/deepcfr-texas-no-limit-holdem-6-players/pull/113) stays draft.

## Frozen experiment

- Source: `204e351def48a630a795ffd1d67d7df03871afc1`, dependent on draft #112. The later documentation commit did not change execution.
- Game: three actual players, 20BB reset per hand, 0.5/1 blinds, standard 52-card deck, no rake/ante. A fold retains three-seat history.
- Recipe: from-zero K1 external sampling, unchanged linear-iteration regret updates, ordered button-relative history, named legacy postflop card descriptor, min/pot/conditional-jam actions with two raises per street, no free folds. Final-current C was fixed before outcomes.
- Three seeds: 2026092901/02/03. Fixed checkpoints: 2M/5M/10M/20M. No extraction/checkpoint selection or budget extension used playing results.
- [Outcome-free preflight](tp20-resource-preflight.json) and [resource decision](tp20-resource-decision.json) selected 20M nodes per seed. The canonical plan digest remains `efc2e794c76db36568530e9cd5239ecf4bb80d17e1a2bc4c5a648eb6ee312690`.
- Each primary lineup contains two independently randomized copies of its specified opponent type. Deals, button, opponent assignments and separate action streams are paired across arms; three hero positions form one independent block. Mixed lineups reverse opponent order on odd blocks.
- Primary: 4,096 blocks per lineup; average three seed differences within each block, then equally weight six fixed lineups. The 95% interval uses within-lineup block variances and Welch/Satterthwaite degrees of freedom. Individual seed/lineup, mixed and crossplay intervals are unadjusted diagnostic intervals, not additional promotion gates.

## Retrieve and play

The demo uses seeds 2026092901 and 2026092902 by fixed order. Their hashes were verified after retrieval. From a checkout of this draft PR, use its installed Python environment:

```sh
mkdir -p results/tp20-demo
scp m4:/Users/dberweger/Local/tp20-pr113/results/tp20-m4-20260928/training/2026092901/current.json.gz results/tp20-demo/2026092901.json.gz
scp m4:/Users/dberweger/Local/tp20-pr113/results/tp20-m4-20260928/training/2026092902/current.json.gz results/tp20-demo/2026092902.json.gz
python -m scripts.play_tp20 \
  --policies results/tp20-demo/2026092901.json.gz results/tp20-demo/2026092902.json.gz \
  --hashes c12ac92e9512413e6d83ed806dd0b7a60d88ef8418099294049b14af5700edd6 77d704f9dbdfae569917f9293f8580fa9c9eea4777eb5c44d7ae3d5f5d47962b \
  --history results/tp20-human.jsonl
python -m scripts.play_tp20 --replay results/tp20-human.jsonl
```
