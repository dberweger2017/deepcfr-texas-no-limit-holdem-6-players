Keep the binary byte-identical (SHA256 `fb32974d9d211fa66001d1efb330ec4af2d825005d24b287dc6cf3c37fa8812f`) and prepare separate restored compact files: `eq50-fit0` carries global K=50 and `eq50-fit1` carries global K=200. These are explicit transport aliases, not fitted codebooks. The adapter obtains every legal holding/runout label through #163’s unchanged class-key/hash/table reader. It regenerates the card-dependent pool-key maps using the existing public-history/menu templates. Blocked holdings retain sentinel 65535. V1 policy, public ranges, tree, seat mapping and board weights remain frozen. Global runs collect only v1 and these two global metrics; the original fitted matrices remain in immutable input copies.

#163’s binding collection requirement applies: regenerate all 120 deterministic equilibrium/collection jobs, then fit each lineage’s two opposite-half witnesses from new global-label statistics. Old v1/corpus-fit aggregate statistics cannot be reprojected. Score both K values in 120 zero-iteration lock-only jobs against hash-linked original equilibrium references. A legacy-board rerun first compares original v1 and fitted equity-50 measurements and equilibrium values with #149. New collections must match the frozen equilibrium values/residuals and original blueprint/per-root metrics. Any mismatch or failed resource/scientific gate stops dependent work.

## Frozen measurements and decision

Forty roots, three B500M lineages, both seats, #149’s frozen 20/20 split, ranges, action trees, board weights and uniform absent/zero-training-mass fallback. Report held-out loss E in BB per spot for global K=50 and K=200 alongside recorded v1, fitted equity-50, per-root and blueprint. Use 2,000 paired-board bootstrap draws, seed 202610030304, sorted spot IDs, retaining lineage/seat pairing. Intervals condition on fixed opposite-half witnesses; they omit fitting uncertainty. No outcome-dependent roots, K selection, budget extension or exclusions.

Primary pass requires both `abs(E_global50 - 0.3874) <= 0.10 BB` and its 95% interval upper bound `< 0.6273 BB`, the recorded v1 lower bound. Inherited missing-reach coverage must be at most 5% in every K/fold/lineage/street cell. Report K=200 descriptively against K=50, including unique card labels and public-history/card key counts by street and fold. If primary fails, inspect coverage, table/class-key compatibility and turn-only versus river-only replacement sensitivities before recommending any implementation. Those sensitivities use the same fitted policies and are descriptive, not extra pass opportunities.

A pass supports the tables as a candidate for step 2’s separately labeled native trainer schema. It is a constructed witness result, not a trained improvement or a full-game strength claim. Steps 2–4 still require Rust/Python parity, trained bench evidence at matched visits per key or plateau, production averaging and direct-play gates.
