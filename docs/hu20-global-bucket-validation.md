Keep the binary byte-identical (SHA256 `fb32974d9d211fa66001d1efb330ec4af2d825005d24b287dc6cf3c37fa8812f`) and prepare separate restored compact files: `eq50-fit0` carries global K=50 and `eq50-fit1` carries global K=200. It regenerates the card-dependent pool-key maps using the existing public-history/menu templates. Blocked holdings retain sentinel 65535. V1 policy, public ranges, tree, seat mapping and board weights remain frozen. Global runs collect only v1 and these two global metrics; the original fitted matrices remain in immutable input copies.

#163’s binding collection requirement applies: regenerate all 120 deterministic equilibrium/collection jobs, then fit each lineage’s two opposite-half witnesses from new global-label statistics. Old v1/corpus-fit aggregate statistics cannot be reprojected. Score both K values in 120 zero-iteration lock-only jobs against hash-linked original equilibrium references. A legacy-board rerun first compares original v1 and fitted equity-50 measurements and equilibrium values with #149. New collections must match the frozen equilibrium values/residuals and original blueprint/per-root metrics. Every lock job also scores a regenerated held-out v1 control and checks it against #149’s recorded v1 witness, using its existing best-response parity tolerance. This is a reproduction gate, not another outcome to select on. All eighteen replay jobs selected by #149’s frozen split also repeat global statistics and check lock-only versus solved-tree best responses. Any mismatch or failed resource/scientific gate stops dependent work.
